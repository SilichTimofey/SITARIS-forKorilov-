# Ветка для коллеги (KirBogle)

Репозиторий: https://github.com/SilichTimofey/SITARIS-forKorilov-

## Что сделать KirBogle
1. Принять приглашение в Collaborators (письмо GitHub или https://github.com/SilichTimofey/SITARIS-forKorilov-/invitations )
2. Клонировать репозиторий / сделать fetch
3. Переключиться на ветку: `git checkout feature/kirbogle`
4. Внести изменения (например, дописать этот файл или добавить свой)
5. `git add .` → `git commit --trailer "Co-authored-by: Cursor <cursoragent@cursor.com>" -m "KirBogle: ..."` → `git push origin feature/kirbogle`
6. На GitHub открыть **Pull Request** из `feature/kirbogle` в `main`

Владелец (SilichTimofey) примет PR.
