## 3. Прокси сети вуза

```bash
git config --global http.proxy http://dune%5CLogin:Password@192.168.40.21:8080
git config --global http.sslVerify false
```

`%5C` = `\`; подставь свой `Login`/`Password` домена dune.  
Вне аудитории: `git config --global --unset http.proxy`.

## 4. Что выполнено

| Шаг | Команды / результат |
|---|---|
| Clone пустого repo | `git clone …` → ветка `main` |
| Файлы + commit | `README.md`, `hello.txt` — Initial commit |
| Правка | учёт **s/n** |
| Ветка | `feature_license_check` → `feature.txt` → merge → удаление ветки |
| `.gitignore` | игнор `*.log`, `my_notes.txt` |
| Конфликт | `john_branch` / `tim_branch` → `print_catalog.js` → разрешение |
| **Push** | `git push -u origin main` ✅ |

Повтор: `python run_lr8_on_github.py` (если клон уже с историей — сначала очистить/переклонировать).
